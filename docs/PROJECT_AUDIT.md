## Paper interpretation

RQ1 distinguishes advice from authority to allocate. RQ2 limits models to evidence preparation and review. RQ3 compares a fixed-order greedy baseline with CP-SAT and an independent exact oracle over all 512 small admissibility patterns. Sections III–VI specify provenance, three-valued eligibility, evidence-weighted matching, scoped retrieval and authorized publication. Sections VIII–IX specify prospective consented field evaluation and risks. Section VII is the only completed experiment in the paper. The paper does not establish live agent quality, production recommendation accuracy, provider compatibility, real allocation outcomes or fairness.

## Runtime and preservation

Baseline command used the prepared Python environment and ran the backend test suite with a temporary directory inside this chat workspace. **27 passed**, with 13 upstream deprecation warnings. Tests use SQLite in memory and deterministic fixture mode. The Next.js TypeScript check passed. Docker Compose configuration parsed. Docker Engine was unavailable on its named pipe. An isolated production-style FastAPI startup against PostgreSQL on port 55432 failed during checkpointer connection with a timeout. The SQLite file was opened read-only. Legacy schema table names: allocation_runs, applicants, internships, login_sessions, policies, system_state, users. The production API points at PostgreSQL and does not read the legacy SQLite file. Existing JSON validation reports and screenshots are historical artifacts, not results of this audit.

Preserve API and Next.js dashboard, authorization/ownership helpers, durable checkpoint design, official catalog assets, and migration history. No untracked work was erased. The build-only frontend dist directory and second backend tree are candidates for later cleanup after use is confirmed. No dependencies were reinstalled. Compose and the proxy use DATABASE_URL, CHECKPOINT_URL, ADMIN_EMAIL, ADMIN_PASSWORD, UPLOAD_DIR, LLM_MODE, LLM_BASE_URL, LLM_MODEL, LLM_API_KEY, EMBEDDING_MODE, ALLOW_MODEL_DOWNLOAD and API_INTERNAL_URL. No actual secret file or private data is included in the source backup.

Priority is to fix trust boundaries before enabling new writes, then align matching and solver semantics, finish the evidence gates, and rerun the isolated experiment and browser journey. Some existing tests encode behaviors that contradict the paper and must be changed only where the corresponding contract changes.
